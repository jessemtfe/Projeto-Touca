# 🎓 Turma da Touca - Plataforma Educacional de Python

## 📌 Sobre o Projeto

O **Turma da Touca** é uma plataforma educacional desenvolvida com o objetivo de ensinar programação para crianças de forma simples, acessível e interativa.

O projeto foi criado em parceria com a ONG **Turma da Touca**, focando em crianças de **9 a 14 anos** que possuem pouco ou nenhum contato com tecnologia. A proposta da plataforma é introduzir conceitos básicos de **Python** através de videoaulas e atividades práticas.

---

## 🚀 Funcionalidades

✅ Sistema de cadastro e login  
✅ Página de atividades  
✅ Sistema de ranking  
✅ Área de videoaulas  
✅ Questões de múltipla escolha em cada aula  
✅ Interface simples e intuitiva para crianças

## 🎯 Objetivo do Projeto

O principal objetivo do projeto é proporcionar o primeiro contato de crianças com a programação, utilizando uma metodologia leve, divertida e educativa.

A plataforma busca incentivar:
- O aprendizado tecnológico
- O raciocínio lógico
- O interesse pela programação
- A inclusão digital

---

## 📚 Como Funciona

Cada videoaula possui atividades de múltipla escolha relacionadas ao conteúdo apresentado, permitindo que os alunos pratiquem o que aprenderam de maneira dinâmica.

Além disso, o sistema de ranking ajuda a estimular o engajamento e a participação dos alunos.
