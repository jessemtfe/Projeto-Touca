Aula 5: IF / ELSE

Estruturas condicionais para tomada de decisões

Home > Vídeos > Aula 5

🎥 Vídeo da Aula

📚 O que você vai aprender:

  • Estrutura condicional IF e ELSE
  • Operadores de comparação (==, !=, >, <)
  • Comando ELIF para múltiplas opções
  • Lógica de programação na prática

📝 Atividades da Aula

Atividade 1: Complete o Código

idade = 12
if idade >= 10:
  print('Pode jogar')
____:

  • a) input
  • b) idade
  • c) else
  • d) if

Atividade 2: Lógica Booleana

fome = True
if fome == True:
  print('Hora de comer!')
else:
  print('Sem fome')

  • a) Hora de comer!
  • b) Sem fome
  • c) True
  • d) False

Atividade 3: Comparação de Níveis

jogador = 150
if jogador > 100:
  print("Nível máximo")
else:
  print("Continue jogando")

  • a) Continue jogando
  • b) False
  • c) Nível máximo
  • d) True

Atividade 4: Maior ou Menor

numero = 5
if numero > 10:
  print("Maior")
else:
  print("Menor")

  • a) Maior
  • b) Menor
  • c) True
  • d) False

Atividade 5: Uso do ELIF

idade = 17
if idade >= 18: print("Adulto")
elif 14 <= idade <= 17: print("Adolescente")

  • a) Adulto
  • b) Criança
  • c) 18
  • d) Adolescente
